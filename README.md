# Glance

**The Markdown viewer Windows never had.** It only ever looks.

A lean, live Markdown viewer for Windows. It reads the files you already have,
in place, and reloads the instant you save. No vault. No import. No account, no
telemetry, nothing to feed.

### [Download Glance](https://leifclaesson.github.io/glance/)

Or grab the installer straight from
[the latest release](https://github.com/leifclaesson/glance/releases/latest).
Windows 10 and 11, 64-bit, signed installer.

## What it does

- Live Markdown viewing with browser-style tabs, reloading on save
- A read-only Library that searches the folders you already keep, by name or by
  content, without copying or importing a thing
- Mermaid diagrams, with `glance verify` to catch one that renders as a mess
- Images, icons and transcripts too
- Serve a file to your phone over the LAN, or to a legacy browser
- Export to standalone HTML
