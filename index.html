What it is

A viewer, and only a viewer.

Leif wanted the one thing no free tool would give him: a reader that opens a Markdown file live, renders it beautifully, reloads when it changes, and then gets out of the way. No vault to adopt your notes. No sidecar folder. Glance opens your files where they already live — and only ever looks.

Live files only

Opens files in place and auto‑reloads on change. It watches the parent folder, so it survives editors that save by atomic rename — the tab updates the instant you hit save elsewhere.

Tabs, one window

Open many files as tabs. Double‑click another .md in Explorer and it joins the running window. Ctrl+Tab walks them in most‑recently‑used order.

A photo viewer too

PNG, JPG, GIF, WebP, SVG, ICO, AVIF — scroll to zoom at the pointer, drag to pan, double‑click for fit or 1:1. Pixel art stays crisp; a Windows .ico explodes into a per‑size inspector.

Library, read‑only

Point it at folders you keep and search them by name and content (Ctrl+L). Deliberately not a vault — it indexes in place, never copies, moves, or imports. Remove a folder and it’s forgotten.

Read on your phone

glance --serve hands the same Library to any device on your LAN — rendered identically, read‑only. A browser too old for the real app (a 2014 tablet) automatically gets a plain‑HTML Legacy reader.

It never writes

Read‑only by nature. The one fenced exception — ticking a - [ ] task box — is permission‑gated per file and re‑decidable in Settings. Everything else it will only ever look at.

In view

Obsidian‑grade rendering, watching for a save.

GFM tables and task lists, syntax‑highlighted code, KaTeX math, Mermaid diagrams, [[wikilinks]], callout boxes, and spoilers — sanitized and rendered live. Edit the file in any editor and the tab reloads itself. Watch:

Callouts with their own colour, icon and dog-ear — and a Mermaid flowchart, laid out live.

The paper goblin

A glance is eyes pointed somewhere.

The face wasn’t planned. The app got the throwaway placeholder name Glance before it had an icon — and the name is the only reason anyone thought to draw eyes looking sideways. Two pill eyes with the pupils slid to one side, a dog‑eared corner, three lines of text for a body: a document that is quietly judging your prose.

“The icon shouldn’t look like a Markdown viewer. It should look like something that is glancing at Markdown.”

  • It reads files where they live
  • It reloads the moment they change
  • It refuses before it will guess
  • It never, ever, writes to your files*

* except when you tick a checkbox -- ticking a Markdown task-box writes that one line back, and only that, and only with your OK (re-decidable in Settings).
